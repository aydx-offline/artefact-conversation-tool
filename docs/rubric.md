# Rubric

The code checks and the judge follow this rubric. `docs/methodology.md` says how.

## Good

A case is good when all three candidates are acceptable. Each candidate is Chinese and within length. A candidate uses only facts, dates, and details from the input, fits the named scenario, uses an address that fits the relationship, is specific to this client, and reads like a native speaker on WeChat. On-brand and not pushy are 1–5 items; a 1–5 item passes at 3 or above (see Scoring). The three candidates are three different strategies. English names that the brand allows are not a failure.

## Not acceptable

- Not three Chinese candidates within length
- Three candidates that are the same strategy
- Urgency or false scarcity
- An unallowed discount
- An unknown product
- A fact, date, or detail that was not in the input
- A missed case expectation
- A template opener that would fit any client
- An address that does not fit the relationship
- Translationese or officialese

## Scoring

Brand fit is a 1–5 judge item.

| Rubric item | Scored by |
| --- | --- |
| Three candidates, Chinese, length | Code checks |
| Three different strategies | Code checks |
| Urgency or false scarcity | Code checks |
| Unallowed discount | Code checks |
| Unknown product | Code checks |
| Facts, dates, and details come from the input | Judge, pass or fail |
| Case expectations met | Judge, pass or fail |
| Fits the scenario | Judge, 1–5 |
| Address fits the relationship. Formal cases can use 您. Familiar cases have no fixed address: 您, 你, 亲, 亲爱的, or the name all score well when natural. | Judge, 1–5 |
| Specific to this client, not a template opener | Judge, 1–5 |
| Chinese a native speaker would send on WeChat. Translationese and officialese score low. | Judge, 1–5 |
| On-brand | Judge, 1–5 |
| Not pushy | Judge, 1–5 |

A candidate is acceptable when every code check passes, both pass-or-fail judge items pass, and no 1–5 item is below 3. A case is good when all three candidates are acceptable.
