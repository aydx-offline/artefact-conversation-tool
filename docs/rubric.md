# Draft rubric

Draft. Do not generate messages until Ann accepts or edits this file.

## Good

A case is good when all three candidates are acceptable. Each candidate is Chinese and within length. A candidate uses only facts, dates, and details from the input, fits the named scenario, matches the relationship and address form, is specific to this client, reads as natural WeChat Chinese, is on-brand, and is not pushy. The three candidates are three different strategies. English names that the brand allows are not a failure.

## Not acceptable

- Not three Chinese candidates within length
- Three candidates that are the same strategy
- Urgency or false scarcity
- An unallowed discount
- An unknown product
- A fact, date, or detail that was not in the input
- A missed case expectation
- A template opener that would fit any client
- The wrong relationship or address form
- Translationese
- A greeting or care message that turns into a hard sell

## Unscored until the brand exists

Brand fit is a 1–5 judge item.

## Scoring

| Rubric item | Scored by |
| --- | --- |
| Three candidates, Chinese, length | Code checks |
| Three different strategies | Code checks |
| Urgency or false scarcity | Code checks |
| Unallowed discount | Code checks |
| Unknown product | Code checks |
| Facts, dates, and details come from the input | Judge, pass or fail |
| Case expectations met | Judge, pass or fail |
| Fits the scenario | Judge, 1–5 |
| Matches the relationship and address form | Judge, 1–5 |
| Specific to this client, not a template opener | Judge, 1–5 |
| Natural WeChat Chinese, not translationese | Judge, 1–5 |
| On-brand | Judge, 1–5 |
| Not pushy | Judge, 1–5 |

A candidate is acceptable when every code check passes, both pass-or-fail judge items pass, and no 1–5 item is below 3. A case is good when all three candidates are acceptable.
